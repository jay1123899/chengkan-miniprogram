## 三、隐私与合规检查（提审前必做）

| 编号 | 检查项 | 检查方式 | 预期结果 | 结果 | 通过 |
| --- | --- | --- | --- | --- | --- |
| P-01 | 代码中无个人信息 | 全项目搜索姓名、学校、邮箱、手机号、QQ/微信号 | 搜不到任何结果 | | ☐ |
| P-02 | 关于页无个人信息 | 打开关于页逐字看一遍 | 只有村落说明、使用说明、内容说明 | | ☐ |
| P-03 | 无评论区 | 全项目搜索"评论""comment" | 无相关代码与页面 | | ☐ |
| P-04 | 无点赞功能 | 全项目搜索"点赞""like""zan" | 无相关代码与页面 | | ☐ |
| P-05 | 未申请用户信息 | 检查 `app.json` 与代码 | 无 `getUserProfile`、无手机号授权、无 `wx.login` 换用户体系 | | ☐ |
| P-06 | 图片不含隐私 | 逐张检查照片 | 无清晰人脸、无门牌号、无车牌、无定位水印 | | ☐ |
| P-07 | 图片无侵权风险 | 确认照片来源 | 均为自己拍摄，或已获授权 | | ☐ |
| P-08 | 文案无夸大宣传 | 检查景点文案 | 无"最""第一""必去"等绝对化表述，无票务承诺 | | ☐ |
| P-09 | 史实已核对 | 对照景区官方资料 | 年代、名称等表述准确 | | ☐ |
| P-10 | 提交身份不泄露 | 检查 git 配置（若开源） | `git config user.email` 用的是 GitHub 提供的 noreply 邮箱 | | ☐ |
