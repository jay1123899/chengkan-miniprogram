# 呈坎旅游宣传小程序

微信小程序原生开发项目，用于徽州古村落"呈坎"的景点介绍与游览引导。

## 功能

| 模块 | 说明 |
| --- | --- |
| 首页 | 顶部 5 张轮播图（自动播放、可左右滑动、点击进入对应景点）+ 特色推荐 |
| 景点 | 关键词搜索、分类筛选（古建 / 古民居 / 水景 / 民俗）、景点列表 |
| 详情 | 图片集（可滑动、点击放大）、看点、详细介绍、游览提示、位置信息、收藏、分享 |
| 收藏 | 收藏列表、取消收藏（本地缓存，无需登录） |
| 关于 | 村落介绍、使用说明、内容与图片说明 |

**设计上刻意不做的东西**：没有评论区，没有点赞，没有排行榜，不收集任何用户信息，不请求登录，不接入后端。页面只做景点信息展示。

**隐私说明**：小程序代码、数据与页面文案中**不包含任何个人身份信息**（姓名、学校、邮箱、手机号、社交账号）。如需对外发布，可直接提审。

## 跑起来（3 步）

1. 打开**微信开发者工具** →「导入项目」
2. 目录选 `chengkan-miniprogram`，AppID 填自己的（没有就点「测试号」）
3. 点「编译」，模拟器里就能看到首页

## 插入照片

**图片全部留空也能正常运行** —— 会显示渐变占位块，不会破图。所以可以先把文案写完，再慢慢补图片。

| 用途 | 改哪里 | 字段 |
| --- | --- | --- |
| 首页轮播图（5 张） | `data/banners.js` | `image` |
| 景点列表缩略图 | `data/spots.js` | `image` |
| 景点详情图集 | `data/spots.js` | `images`（数组，可多张） |

图片可以是本地路径 `'/images/xxx.jpg'`，也可以是网络地址 `'https://...'`。
命名规范、尺寸建议和**体积限制**见 `images/README.md` —— 特别注意：**小程序主包上限 2MB，图片放本地很容易超限**，务必先压缩，或改用网络图床。

## 几个实现要点

**首页轮播**（`pages/index/index.wxml`）
用原生 `swiper` 组件，`autoplay` + `circular` 实现自动循环播放。每张图用绝对定位的渐变压暗层（`.banner-mask`）承载标题文字，这样有图和无图时排版一致。

**详情页图集**（`pages/detail/detail.js`）
逻辑上做了一级降级：有 `images` 数组 → 用 swiper 显示多图；只有 `image` → 显示单图；都没有 → 显示占位块。点击任意图片调用 `wx.previewImage` 全屏预览，支持左右滑动切换。

**关键词搜索**（`pages/spots/spots.js` 的 `apply()`）
先把景点按分类过滤，再用关键词匹配名称、简介、标签、看点与正文（拼成一个字符串做 `indexOf` 判断），最后 `setData` 渲染。数据量小，所以没有引入分词。

**收藏**（`utils/store.js`）
用 `wx.setStorageSync('ck_favorites', [id...])` 存本地缓存，不依赖服务器。详情页和列表页读同一份缓存，保证状态一致。局限是只在当前设备生效，换手机不同步。

## 用图床放照片（推荐）

图片不一定要放在本地。`data/` 里的 `image` 与 `images` 字段**既支持本地路径，也支持完整网址**：

```js
image: '/images/baolunge-1.jpg',                                  // 本地图片
image: 'https://your-cdn.example.com/baolunge-1.jpg',             // 图床直链
images: ['https://your-cdn.example.com/a.jpg', 'https://.../b.jpg'],
```

用图床的好处：**小程序包体零占用**，主包永远轻，加载也不占用用户下载流量之外的额度。

**关键点**：`<image>` 组件加载外链图片**不需要**在 mp 后台配置服务器域名（只有 `wx.request`、`wx.downloadFile`、`wx.uploadFile`、`wx.connectSocket` 需要）。所以图床地址填进去就能用。

**选图床要注意的四件事**：

| 注意点 | 说明 |
| --- | --- |
| 必须 https | 小程序不允许 http 图片 |
| 稳定性 | 免费图床可能限流、跑路、清理旧图。图片一旦失效，对应位置会退回渐变占位块（项目已做加载失败回退，不会出现空白或破图） |
| 防盗链 | 部分图床开启防盗链后，在小程序里会加载失败 |
| 访问速度 | 国外图床在国内访问慢，建议用国内节点 |

**推荐顺序**：微信云开发「云存储」（同生态、有免费额度、最稳）→ 国内云厂商对象存储（阿里云 OSS / 腾讯云 COS）→ 免费图床（省事但有失效风险）。

**怎么批量填地址**：在项目根目录（`D:\n`）编辑 `image_urls.txt`，把每张图的直链填在等号右边，然后运行：

```
python set_image_urls.py
```

脚本会自动把地址写进 `data/banners.js` 和 `data/spots.js`。没填的行保持原样 —— 也就是说**本地图片和图床地址可以混用**：常用的几张放本地，其余走图床。


## 上传与发布

1. 微信开发者工具点「上传」，填版本号与备注
2. 登录 [mp.weixin.qq.com](https://mp.weixin.qq.com) → 版本管理 → 提交审核
3. 审核通过后点「发布」

> 提审前请对照 `docs/自测记录表.md` 最后一节的检查清单过一遍，尤其是图片是否含人脸/门牌/车牌，以及内容是否为真实资料。
